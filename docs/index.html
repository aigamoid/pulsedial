PulseDial

Spotify remote for M5Stack StopWatch

1. Install / インストール

Connect the StopWatch with a USB-C cable, then press the button. Use Chrome or Edge on a PC.
USB-C で StopWatch を PC につなぎ、ボタンを押します（PC の Chrome か Edge で開いてください）。

This browser can't write to USB devices. Please use Chrome or Edge on a PC.
このブラウザは USB 機器に書き込めません。PC の Chrome か Edge を使ってください。 Open this page over https (or localhost).

Choose USB JTAG/serial debug unit as the port. If asked to erase, you can leave it unchecked.
ポートは USB JTAG/serial debug unit を選びます。Erase は聞かれてもチェックなしで大丈夫です。

This replaces the firmware on the StopWatch (the official apps stay in the menu). See the README to go back to the official firmware.
本体のファームウェアを書き換えます（公式のアプリもメニューに残ります）。元に戻す方法は README にあります。

2. Wi-Fi

  1. Open PulseDial on the StopWatch. If it has no Wi-Fi yet, it shows a QR code.
    StopWatch で PulseDial を開きます。Wi-Fi が未設定なら QR コードが出ます。
  2. Scan it with your phone, then open 192.168.4.1 and choose your home Wi-Fi (2.4 GHz).
    スマホで読み取り、192.168.4.1 を開いて家の Wi-Fi（2.4 GHz）を選びます。

3. Spotify

  1. Create your own app at developer.spotify.com/dashboard (Spotify Premium is required) with the Redirect URI http://127.0.0.1:8888/callback.
    Spotify の開発者ページで自分用のアプリを作ります（Premium が必要）。
  2. Download this repository (ZIP), unzip it, and run python3 tools/spotify_login.py (Windows: py tools\spotify_login.py, Python 3.9+). Enter the Client ID, and the IP and PIN shown on the StopWatch.
    リポジトリを ZIP でダウンロードして展開し、spotify_login.py を実行します（Windows は py）。 Client ID と、本体に出る IP・PIN を入れます。
